# Simple Calculator

A clean, web-based calculator application built to perform basic arithmetic operations smoothly. This project features a user-friendly interface and responsive design.

## Features

* **Basic Arithmetic:** Supports Addition (`+`), Subtraction (`-`), Multiplication (`*`), and Division (`/`).
* **Clear Functionality:** Quickly reset the calculator using the `C` (Clear) button.
* **Responsive Design:** Works flawlessly on both desktop and mobile screens.
* **User-Friendly UI:** Modern and intuitive interface for an effortless user experience.

## Technologies Used

* **HTML5:** For the structure and layout of the calculator.
* **CSS3:** For styling, colors, and responsive design.
* **JavaScript:** For the logical calculations and button interactions.

## How to Use

1. Clone or download this repository.
2. Open the `index.html` file in any modern web browser.
3. Start calculating!
